# Glossary

Shared vocabulary for the LOOP product case study.

| Term | Meaning |
|------|---------|
| **LOOP** | iPhone app for students and early builders to find people to build with and actually start |
| **Learner / Builder / Mentor** | How a member mainly shows up (user type) |
| **Looking for** | Declared intent: build partner, hackathon team, co-founder, someone to learn with |
| **Offered / needed roles** | What a member can do (backend, UI/UX, iOS…) and what they need from a partner |
| **Fit %** | How well two members complete each other, with a one-line reason |
| **Connect request** | Explicit ask to become build partners |
| **Match moment** | The screen shown when a partnership starts |
| **Build partner** | Two members in a partnership with a private chat |
| **Challenge dice** | Rolls a real problem for a new pair to build, with starter files |
| **Hackathon team listing** | Recruiting post with open seats per role, team size, commitment and idea |
| **Open seat** | A role a team still needs; teams are hidden from recruiting once full |
| **Join request** | Request to take an open seat; `pending` → `accepted` \| `declined` \| `expired` |
| **Team group** | Chat and live voice space for an accepted team |
| **Looking For post** | Public "I need X" post in Communities; others express interest |
| **Share link** | `loopbuilders.app` link that opens the app on the right screen, with a ready message |
| **Early Builder** | Badge for the first members |
| **North star** | Partnerships that started real work within 2 weeks |
| **Weekly active collaboration** | A partnership or team that worked together in a given week |
| **Report / block** | Safety tools on every profile, post and message; reports reviewed within 24h |
| **Platform role** | Staff role (`moderator` / `admin` / `founder`), separate from user type |
| **OTA update** | Over-the-air app update for screen and text fixes, without a store build |

For architecture terms, see [System Architecture Overview](../architecture/system-architecture-overview.md).
