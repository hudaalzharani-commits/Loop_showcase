# Screenshots

Product captures for the LOOP showcase.

## How to add captures

1. Open the live app: [https://loop-hazel-sigma.vercel.app](https://loop-hazel-sigma.vercel.app)
2. Capture the surfaces below (mobile width ~390px recommended)
3. Save PNGs into this folder using the filenames listed
4. Update the main [README](../README.md) screenshot section to embed them

## Capture notes

- Prefer English UI strings (product language)
- Avoid showing real emails, private tickets, or PII
- Crop browser chrome when possible
- Keep filenames stable so README links do not break
